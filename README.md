# 📚 StudyFlow

StudyFlow is a simple and responsive study planner web application that helps students organize their study schedule, manage tasks, and track their learning progress.

## 🚀 Features

- 📝 Add, edit, and delete study tasks
- ✅ Mark tasks as completed
- 🔍 Search tasks instantly
- 🎯 Filter tasks by priority and status
- 📅 Due date management
- 📊 Progress tracker with completion percentage
- 🔥 7-day study streak tracker
- ⏱️ Focus timer for productive study sessions
- 💾 Data stored using LocalStorage
- 📱 Responsive design for desktop and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser LocalStorage
